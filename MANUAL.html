1. Visão Geral do Projeto

O ConciliaAI Mobile é um aplicativo de finanças pessoais desenvolvido em React Native com Expo. Ele é a versão mobile do sistema web ConciliaAI, permitindo que os usuários gerenciem receitas, despesas, cartões, grupos financeiros e planejamento diretamente pelo celular.

O app se comunica com o backend via API REST hospedada no Render, utiliza JWT para autenticação e Asaas como gateway de pagamento para assinaturas.

O que o usuário pode fazer

  • Lançar receitas e despesas
  • Ver dashboard com saldo
  • Gerenciar categorias
  • Controlar cartão de crédito
  • Importar extrato OFX
  • Lançar por foto (IA)
  • Ver relatórios
  • Gerenciar grupos
  • Planejar finanças
  • Assinar planos

Segurança implementada

  • JWT no SecureStore
  • Biometria (FaceID/digital)
  • Lock após 5min background
  • Email/CPF mascarados
  • Error boundary
  • Logout automático

Infraestrutura

  • Backend: Node.js / Render
  • Banco: PostgreSQL / Render
  • Pagamentos: Asaas
  • Build: EAS (Expo)
  • Distribuição: Play Store
  • Notificações: Web Push

3. Arquitetura do App

index.ts (ponto de entrada) └── App.tsx ├── ErrorBoundary ← captura crashes ├── AuthProvider ← estado de login global ├── Navigation ← decide qual tela mostrar │ ├── [não logado] LoginScreen │ └── [logado] BiometricGate │ └── AppNavigator (todas as telas) ├── ToastContainer ← mensagens flutuantes └── OfflineBanner ← aviso de sem internet

4. Fluxos Principais

Fluxo de Login

LoginScreen → POST /api/auth/login → recebe JWT → salva token no SecureStore (expo-secure-store) → AuthContext.signIn() → isLoggedIn = true → Navigation redireciona para AppNavigator → BiometricGate solicita FaceID/digital → DashboardScreen carrega

Fluxo de Pagamento / Assinatura

PlanosScreen → usuário toca "Assinar" → verifica CPF (se não tiver, abre modal para informar) → POST /api/payments/checkout → recebe invoiceUrl → Linking.openURL(invoiceUrl) → abre Asaas no browser → usuário paga → Asaas chama webhook do backend → backend atualiza subscription para "Active" → usuário volta ao app → AppState detecta retorno → polling /api/subscriptions/me a cada 5s → quando "active" → toast "Assinatura ativada!" → volta ao Perfil

Fluxo de Biometria

App abre (usuário logado) → BiometricGate verifica disponibilidade de hardware → [disponível] solicita FaceID/digital → [aprovado] exibe app normalmente → App vai para background → salva timestamp no SecureStore → App volta para foreground → verifica se passou 5min → [passou] bloqueia + solicita autenticação novamente

Fluxo de Importação OFX

ImportarExtratoScreen → usuário seleciona arquivo .ofx → ofxParser.ts faz parse do arquivo localmente → exibe prévia das transações encontradas → usuário confirma → POST /api/finance-items (lote) → salva saldo do extrato na conta bancária

5. Arquivos de Configuração

app.json

app.json Config

Configuração principal do Expo. Define nome do app, ícone, splash screen, versão, package name Android e bundle identifier iOS. Também armazena o ID do projeto EAS gerado automaticamente.

⚠️ O package name Android é br.app.conciliaai.www.twa — precisa ser IGUAL ao que está no Google Play Console para que o build substitua o app existente.

eas.json

eas.json Config

Configuração do EAS Build (serviço de compilação do Expo). Define 3 perfis de build:

  • development — para testar com Expo Dev Client no celular
  • preview — distribuição interna (APK para testar antes de publicar)
  • production — gera o .aab para a Play Store, com auto-increment de versão

package.json

package.json Config

Lista todas as dependências do projeto e scripts de execução. Scripts principais: start (inicia o servidor de desenvolvimento), android (roda no Android), ios (roda no iOS).

tsconfig.json

tsconfig.json Config

Configuração do TypeScript. Define as regras de tipagem do projeto.

6. Ponto de Entrada

index.ts

index.ts

Arquivo inicial do app. Registra o componente raiz usando registerRootComponent do Expo — equivalente ao AppRegistry.registerComponent do React Native puro. É o primeiro arquivo executado.

App.tsx

App.tsx

Componente raiz da aplicação. Monta toda a estrutura global:

  • ErrorBoundary — envolve tudo para capturar crashes inesperados
  • StatusBar — define a barra de status do sistema como escura
  • AuthProvider — fornece o estado de autenticação para todas as telas
  • Navigation — componente que decide quais telas mostrar
  • ToastContainer — renderiza mensagens flutuantes de erro/sucesso
  • OfflineBanner — mostra banner vermelho quando sem internet

7. Navegação

navigation/index.tsx

src/navigation/index.tsx Navegação

Centro de controle de navegação do app. Define 3 navegadores:

  • AuthNavigator — pilha com apenas a LoginScreen (para usuários não logados)
  • TabNavigator — barra inferior com 5 abas (Home, Categorias, Add, Grupos, Planejamento)
  • AppNavigator — pilha principal com todas as telas do app logado

A lógica principal: se isLoggedIn (do AuthContext) for verdadeiro, mostra o AppNavigator envolto no BiometricGate. Caso contrário, mostra o AuthNavigator.

navigation/rootNav.ts

src/navigation/rootNav.ts Navegação

Exporta uma referência global ao NavigationContainer (navigationRef) e uma função rootNavigate(screenName). Isso permite navegar para qualquer tela de dentro de funções que não têm acesso ao useNavigation hook — por exemplo, dentro de sections.tsx.

navigation/CustomTabBar.tsx

src/navigation/CustomTabBar.tsx Navegação

Barra de abas inferior totalmente customizada. Diferente da tab bar padrão do React Navigation, esta tem um botão central "+" flutuante, animações de entrada/saída e integração com o scroll do dashboard para esconder/mostrar automaticamente.

navigation/tabBarScroll.ts

src/navigation/tabBarScroll.ts Navegação

Módulo que controla a visibilidade da tab bar baseado no scroll. Quando o usuário rola o dashboard para baixo, a tab bar se esconde. Quando rola para cima, ela reaparece.

navigation/fabAnimState.ts

src/navigation/fabAnimState.ts Navegação

Estado compartilhado da animação do botão FAB (Floating Action Button) central na tab bar.

navigation/groupFabAction.ts

src/navigation/groupFabAction.ts Navegação

Controla a ação do botão FAB quando o usuário está na tela de Grupos — permite criar um novo grupo diretamente pelo botão central.

8. Contextos (Estado Global)

context/AuthContext.tsx

src/context/AuthContext.tsx Contexto

Único contexto global do app. Gerencia o estado de autenticação:

  • isLoggedIn — booleano que define qual navegador mostrar
  • signIn(token, user, planName) — salva token + dados do usuário no SecureStore e marca como logado
  • signOut() — limpa todos os dados salvos e desloga

Na inicialização, verifica se existe um token salvo no SecureStore para manter o usuário logado entre sessões.

9. Bibliotecas (lib/)

lib/api.ts

src/lib/api.ts Lib

Exporta a função apiUrl(path) que monta a URL completa para chamadas à API do backend. Centraliza o endereço base da API para facilitar troca entre ambientes (desenvolvimento/produção).

lib/auth.ts

src/lib/auth.ts Lib

Funções de autenticação que interagem com o SecureStore (armazenamento seguro e criptografado do dispositivo):

  • getToken() — recupera o JWT salvo
  • saveToken(token) — salva o JWT
  • saveUser(user) — salva dados do usuário em cache
  • getUser() — recupera dados do usuário em cache
  • getEmailFromAnySource() — busca o email de qualquer fonte disponível
  • decodeUserId(token) — extrai o userId do payload do JWT sem validar a assinatura
  • logout() — limpa todos os dados salvos

lib/financeService.ts

src/lib/financeService.ts Lib

Serviço principal de transações financeiras. Exporta fetchFinanceItems() que busca todas as transações do usuário na API e fmt(cents) que formata valores em Real brasileiro (R$).

lib/bankAccountsService.ts

src/lib/bankAccountsService.ts Lib

Serviço para gerenciar contas bancárias. Funções: listBankAccounts(), createBankAccount(), updateBankAccount(), deleteBankAccount(). Usado pelo Dashboard para exibir o carrossel de cartões e sincronizar saldos.

lib/financeCategoriesService.ts

src/lib/financeCategoriesService.ts Lib

Serviço para gerenciar categorias personalizadas do usuário. CRUD completo de categorias via API.

lib/creditCardService.ts

src/lib/creditCardService.ts Lib

Serviço para operações de cartão de crédito — busca faturas, lança pagamentos de fatura, gerencia o limite e gastos do cartão.

lib/groupsService.ts

src/lib/groupsService.ts Lib

Serviço para grupos financeiros compartilhados. Funções para listar, criar, entrar, sair e gerenciar membros de grupos.

lib/dateUtils.ts

src/lib/dateUtils.ts Lib

Utilitários de data usados em todo o app:

  • todayISO() — data de hoje no formato YYYY-MM-DD
  • addMonthsYM(ym, n) — adiciona N meses a uma string "YYYY-MM"
  • addDaysISO(date, n) — adiciona N dias a uma data ISO
  • dateLabel(dateISO) — converte data ISO para texto amigável ("Hoje", "Ontem", "15 jun")

lib/catUtils.ts

src/lib/catUtils.ts Lib

Utilitário que mapeia nomes de categorias para emojis. A função catIcon(categoryName) retorna o emoji correspondente à categoria (ex: "Alimentação" → 🍔, "Transporte" → 🚗).

lib/ofxParser.ts

src/lib/ofxParser.ts Lib

Parser de arquivos OFX (Open Financial Exchange) — formato de extrato bancário. Lê o arquivo diretamente no dispositivo (sem enviar ao servidor) e extrai as transações, datas e valores. Suporta arquivos de múltiplos bancos brasileiros.

10. Componentes Globais

components/BiometricGate.tsx

src/components/BiometricGate.tsx Componente

Portão de segurança biométrico. Envolve todo o app logado e:

  • Na abertura do app: solicita FaceID ou impressão digital
  • Quando o app vai para background: salva o timestamp atual
  • Quando o app volta do background: se passaram mais de 5 minutos, bloqueia e pede autenticação novamente
  • Se o dispositivo não tem biometria configurada: deixa passar sem bloquear
  • Exibe tela de bloqueio com botão "Desbloquear" se a autenticação falhar

components/ErrorBoundary.tsx

src/components/ErrorBoundary.tsx Componente

Componente de classe (obrigatório para Error Boundaries no React) que captura erros não tratados em qualquer tela. Em vez de travar o app com tela branca, exibe uma tela amigável com botão "Tentar novamente". Essencial para produção.

components/Toast.tsx

src/components/Toast.tsx Componente

Sistema de mensagens flutuantes (toasts). Exporta:

  • showToast(message, type) — função global chamável de qualquer lugar do app
  • ToastContainer — componente renderizado no App.tsx que exibe as mensagens

Tipos: "error" (vermelho), "success" (verde), "info" (azul). A mensagem aparece no topo da tela com animação de fade e desaparece em 3,5 segundos.

components/OfflineBanner.tsx

src/components/OfflineBanner.tsx Componente

Banner vermelho que aparece no topo da tela quando o dispositivo perde conexão com a internet. Usa @react-native-community/netinfo para monitorar a conectividade em tempo real. Desliza para baixo ao perder conexão e sobe ao reconectar.

components/TransferenciaModal.tsx

src/components/TransferenciaModal.tsx Componente

Modal para registrar transferências entre contas bancárias do usuário. Lança automaticamente uma despesa em uma conta e uma receita em outra.

components/DonutCounter.tsx

Gráfico de rosca (donut chart) animado, usado na tela de Planejamento para visualizar orçamentos e metas.

21. Planos e Notificações

screens/app/planos/PlanosScreen.tsx

src/screens/app/planos/PlanosScreen.tsx Tela

Tela de assinatura de planos. Busca os planos disponíveis na API e exibe cards com preço, recursos e botão de assinar. Fluxo:

  • Verifica se usuário tem CPF cadastrado (obrigatório pelo Asaas)
  • Se não tiver: abre modal para informar CPF
  • Chama POST /api/payments/checkout → recebe link do Asaas
  • Abre o link no browser via Linking.openURL()
  • Detecta retorno ao app via AppState
  • Exibe overlay "Verificando pagamento..." e faz polling a cada 5s por 1 minuto

Resumo da Arquitetura

Fluxo de Dados

  • API REST → lib/services
  • JWT no SecureStore
  • Estado local por tela
  • AuthContext global
  • Sem Redux/Zustand

Padrão de Arquivos

  • Screen = tela completa
  • shared.ts = estilos+tipos
  • sections.tsx = partes da tela
  • components/ = reutilizáveis
  • lib/ = chamadas API

Segurança

  • JWT expirado = logout
  • Biometria na abertura
  • Lock 5min background
  • Dados sensíveis mascarados
  • SecureStore criptografado
